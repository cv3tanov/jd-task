## Export

```lua
exports['jd-task']:Show('Намери автомобила.', 'Нова задача')

exports['jd-task']:Show('Достави автомобила.', 'Нова задача', {
    duration = 20 * 60 * 1000,
    timerLabel = 'Оставащо време'
})

-- Обновява без повторна анимация и премигване.
exports['jd-task']:Update('Закарай автомобила до отбелязаното място.', 'Нова задача')

-- Премахва задачата окончателно.
exports['jd-task']:Hide()

-- Скрива или показва задачата, без да я изтрива.
exports['jd-task']:Toggle()
```

## Клавиш G

`G` само скрива активната задача. 
При повторно натискане тя се показва отново с актуалния текст и оставащо време.

За приключване на задача използвайте `Hide()`, за да не може старото съобщение да бъде върнато с `G`.
