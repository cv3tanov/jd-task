## Използване

```lua
exports['jd-task']:Show('Закарай автомобила до отбелязаното място.')
exports['jd-task']:Show('Намери правилния автомобил.', 'Нова задача')
exports['jd-task']:Hide()
```

Редът е `Show(описание, заглавие)`. 
Заглавието е опционално. Клавишът и текстовете се настройват в `config.lua`; 
по подразбиране `G` скрива интерфейса.
